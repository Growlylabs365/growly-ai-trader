# 🚀 Growly AI Trader

## Vision

Growly AI Trader is an institutional-grade AI trading assistant designed to analyze financial markets using Smart Money Concepts (SMC), ICT principles, Price Action, Liquidity, Market Structure, Order Blocks, and Fair Value Gaps.

Our goal is not to generate many signals.

Our goal is to generate only the highest probability trades.

---

- EURUSD
- XAUUSD

---

## Timeframes

- H4 → Trend
- H1 → Market Structure
- M15 → Entry
- M5 → Precision Entry (Future)

---

## Core AI Rules

- Never guess.
- Never chase price.
- Never force a trade.
- Protect capital first.
- Only trade when confidence is high.
- If confidence is below 80%, return **NO TRADE**.
